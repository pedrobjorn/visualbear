Case Study — E-commerce Redesign

Sports E-commerce Redesign

A full redesign of a sports retailer's mobile and desktop web — new brand, new design system, and a coupon system rebuilt from the ground up.

Pedro Björn

Stagnating growth

Retention flat

Usability issues

Hurting both UX and SEO

Feature friction

New features hard to implement on an inconsistent base

New rebrand

Needed across the entire e-commerce experience

Customers returned in spite of the experience — because of the quality of selection and service. Service and selection were great; the site was hard to use, and hard to shop (sheer quantity of selection and information). Features like brand browsing were barely findable.

Goals

  1. Fix usability issues
  2. Standardise the experience so new features ship faster
  3. Implement the rebrand end-to-end

Success metric preview: 15% customer return rate ↑ · SEO + usability improved · Sports Site of the Year award

Exploration

Brand visual redesign

In tandem with site redesign: close brand collaboration embedded identity into UI direction — slanted inclines, rounded corners, occasional sharp corners

Design System

Tokens for fonts, colours, spacing; new Discovery cycle (Ideation → Prototype → Usability Study → Implement → Measure). Unification + validation + brand embedding in one leap

Coupon system enters here as an early signal

Coupons drove 30% of CS tickets and frequent user complaints; UX audit confirmed issues.

"We want to increase the amount of live coupon campaigns, and also increase their conversion rate." — E-commerce Department

Design Decisions

  • Retained information density — customers come seeking information; don't change too much
  • "Combination" pattern — easily add commonly-bought-together items
  • Reviews kept useful but updated to feel more personal
  • Content constraint: imagery still shot 1:1, accommodate while coordinating shift to 2:3

Deep-Dive: Coupon System

The redesign's standardisation made this fix possible — a focused rebuild of the highest-friction flow in the experience.

Users had to copy/memorise codes and input manually; users often tried combining coupons; poorly worded error messages; leaving the site to hunt for coupons → frustration at cart level, poor final impression, drop-off without purchase

Evidence Base

  • Session recordings, remote unmoderated tests (qualitative)
  • GA + internal reporting + CS tickets (quantitative)
  • Competitive analysis

External stat: Competitive prices and valuable promotions beyond free shipping rank in the top 5 factors for retailer choice (Digital Commerce 360/Bizrate Insights, Oct 2019, 1,055 U.S. shoppers)

Actions

  • Workshops mapping flows — touch-points, coupon types, possible combinations, alert messages → ideation → affinity map
  • Improvements:
    • Auto-apply coupons at checkout
    • More coupon alerts & feedback
    • Simplified coupon conditions
    • Refined Coupon Component
  • Campaign Component System in the Design System: coupon component, campaign themes, component rules
  • Detail worth keeping verbatim: "users can still copy/paste codes — it doesn't do anything, but it feels good"
  • CS ticket data view for support

Validation: Quick prototype verified comprehension; hypotheses validated enough to commit; no A/B infrastructure yet — released live

Delivery

01

New components added to Design System

02

User flows + copy documented

03

Developer collaboration for smooth production integration

Site rollout phased per page, mobile + desktop.

Outcome & Lessons

0% return rate ↑
0% CS ticket drop
0 user complaints in feedback
<2% cart abandonment ↓ + CR ↑ on coupon campaigns

Site Outcomes

  • Stickiness + SEO + usability improved
  • Sports Site of the Year awards that year
  • Positive customer reactions on social media

Coupon Learnings

Takeaways

  • Automate it, remove human error
  • CS is a valuable data source
  • "voucher flight" is real (users leaving to hunt coupons)

Reality check

  • Many users still copy/pasted
  • Most users were product-focused, not campaign-focused
  • Coupons had smaller impact than expected
  • Checkout itself unchanged
  • Slight uptick in return users only after a few months

General Lessons

  • Validate early and often with users
  • Design Systems are enablers, not gatekeepers
  • Include Brand in product from day 1
  • Start with a solid foundation and iterate early and often

The coupon study is reframed as proof of the redesign thesis — standardisation (Design System + Discovery cycle) is what made a fast, surgical coupon fix possible. Its sobering learnings are kept verbatim and unhidden; they strengthen, not weaken, the story.
