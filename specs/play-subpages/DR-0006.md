# DR-0006: The photography page goes full-bleed dark grey - scoped per page, never global; the hairline seam and the added h1 are the recorded one-offs

- Date: 2026-11-14
- Status: accepted (Pedro's spec-fix request 2026-11-14: bigger hover border, padding from the header, full-page wider grid, hairline-only seams, dark grey gradient background with matching headline, square corners, lightbox buttons visible in dark)
- Context: `/play/photography/` is the only page with the photogrid + lightbox. Its grid sat inside `.content.gallery` (`max-width: 900px`) with `gap: 16px`, 8px rounded cards and a 2px hover outline; the body brand gradient (red -> dark) is global; the page had no h1; the lightbox `.vb-btn` glyphs are red on a near-black backdrop (~3.9:1, below the 4.5:1 text floor).
- Options weighed: (a) change the shared `.content.gallery` / body gradient / `.vb-btn` globally - rejected, it would re-skin the work/play/blog galleries, every page's background and the case-study button sliders; (b) scope every change to the photography page via `.content.gallery:has(.gallery-grid)`, `.gallery-grid`, `.photoview*`, `.lightbox` and a `body.page-photography` class set through the existing `bodyattrs` block - chosen.
- Decision: (b). Full-bleed grid (`max-width: none; width: 100%`), 24px padding under the sticky switch, `gap: 1px` with a `#0c0c0e` container background so seams are a 1px dark hairline, `border-radius: 0` + no drop-shadow inside the grid, 4px red hover outline inset (`outline-offset: -4px`), dark grey gradient page (`#3a3a41` -> `#18181b` via the `body.home-page` layer pattern so the canvas gradient never tiles), one `<h1 class="photoview-title">Photography</h1>` in `$vb-light`, and lightbox controls in `$vb-light` with a light 2px border on a translucent dark plate. Tickets 18-20.
- Rationale: the photogrid is a photo wall, not a card list - full-bleed with hairline seams and square corners is the coherent look, and the dark grey gradient matches the site's dark end of the brand ramp without touching the red fade every other page keeps. Scoping per page keeps the system intact (design-principle #4). The h1 addition is an ASSUMPTION recorded in Ticket 19: the page had no heading at all, so "headline match it" was read as "add the page headline in light ink on the dark ground" (also fixes the missing-h1 a11y gap).
- Consequences: the seam color `#0c0c0e` and the gradient stop `#3a3a41` are one-off values, not tokens - if a second dark full-bleed page appears, promote them to `$vb-*` tokens then. Changing the photogrid look again means editing the `:has()`-scoped rules in `gallery.scss`, never the shared gallery rules.
