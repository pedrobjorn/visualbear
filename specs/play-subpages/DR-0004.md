# DR-0004: The Play card stays slim (112px) but inside the gallery list, with the title fit fixed in CSS

- Date: 2026-11-14
- Status: accepted (Pedro, 2026-11-14: "can't the play card still be slim but part of the gallery list?"). Supersedes DR-0003's full-size decision; DR-0003's in-gallery placement stays.
- Context: DR-0003 moved Play into the work gallery as a full-size 256px card because the first slim attempt (separate block below `#work`) had its title overflow onto the gallery background. Measured cause: `.card-title` is ~118px tall (16px padding + h2 + p) inside a 112px card; absolutely positioned at `bottom: 0`, it overflows the card's top edge.
- Options weighed: (a) full-size card in the gallery (DR-0003) - works but drops Pedro's original "thinner card" ask; (b) slim 112px card inside the gallery with the title padding reduced from 16px to 8px so the title block (~102px) fits the card - chosen.
- Decision: (b). The gallery's work branch renders the Play card with the card macro's existing `class` passthrough (`class: "card--thin"`, plus the existing `id: "play-teaser"`) - no new macro flag. `card.scss` carries `.card--thin`: height 112px, and `.card--thin .card-container.card.medium .card-image .card-title { padding: 8px 16px; }` (specificity 0,5,0 so it beats the 0,4,0 base rule without `!important`).
- Rationale: slim was the original requirement (DR-0001 "thinner card"); in-gallery placement removes the background collision; the padding fix makes the text fit. No template machinery added - the macro already renders `spec.class`.
- Consequences: acceptance measures BOTH the 112px height AND the title rect inside the card rect (Playwright, 1440 + 390). The mirror strip is unchanged (targets `id="play-teaser"`). If the 8px padding still clips at some width, the lever is the h2 size inside `.card--thin`, not more height.
