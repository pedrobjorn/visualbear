# DR-0007: Eval pass 2026-11-14 - photography controls mirror the system tab look; blog joins the page-anchored fade; placeholders are wired, not stubbed

- Date: 2026-11-14
- Status: accepted (Pedro's eval pass 2026-11-14; the 3164px item resolved via structured question: full-size view images, contain, no crop)
- Context: after DR-0006 the photography page had its own dark gradient, a dark sticky switch bar, red-border view buttons, and a full-size view at natural height. The blog showed the viewport-tile red restart (canvas-propagated gradient re-tiles every viewport height - measured snap to (215,55,53) at y=900 on a 1898px page). blog.json pointed two entries at non-existent pages. The visualbear-system plan had a pending gate to retire /styleguide/ (its Ticket 4); Pedro instead wants the tab strip ON the design system page (separate ticket, md-case-study-editor).
- Options weighed: (a) reuse the tabs molecule markup on the photography switch - rejected, the tabs controller boots on `[data-vb-tablist]` and would try to swap panels that don't exist; the switch stays an aria-pressed group and only mirrors the `.vb-tab` values; (b) give the blog its own copy of the fade-layer CSS - rejected, the `body.home-page` rule just gains the `body.page-blog` selector; (c) placeholder posts as bare md files - rejected, the authoring flow needs page dir + md + project json + blog.json entry or the cards 404.
- Decision: (a/b/c as chosen). Tickets 21-23: `.photoview-switch` transparent; `.photoview-btn` restyled to the `.vb-tab` look (pill, uppercase, 0.18em tracking, underline active, inks #a6adb8 / #ee6e73 on the dark ground, compact breakpoints mirrored); h1 verified above the bar by rects; `.gallery-full img` = `height: var(--photofull-img-height)` with `--photofull-img-height: 3164px`, `object-fit: contain`; `body.page-blog` shares the home-page fade layer on /play/blog/ + all post pages; three wired placeholder posts (blog1/2/3).
- Rationale: one visual language for "tabs" across the site without entangling two controllers; the fade-layer fix is the same root cause as ticket 52, so it reuses the same mechanism instead of a second one; placeholders must be fillable in place, so they ship the full wiring.
- Consequences: the photography switch's ink values (#a6adb8/#ee6e73) are duplicated from tabs.scss - if the strip inks ever change, update both (or promote the strip inks to tokens). `--photofull-img-height` is the single knob for the full-size stage height. Blog posts now carry `page-blog`; any future blog post template must set the same bodyattrs block.
- AMENDED 2026-11-17 (Pedro: "height always matches images, but with a max height of 2048px"): the 3164px fixed stage is gone. `.gallery-full .photofull-item img` is now `width: 100%; height: auto; max-height: 2048px; object-fit: contain` - the rendered height follows each image's own aspect ratio at full width, capped at 2048px (no crop when the cap engages). The `--photofull-img-height` knob is deleted; the cap lives in one place: `max-height` on the img rule in gallery.scss.
