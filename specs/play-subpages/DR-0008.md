# DR-0008: Photography controls - option pills take the page's base background color; title + bar align to the 900px content line

- Date: 2026-11-14
- Status: accepted (Pedro's eval pass round 3, 2026-11-14)
- Context: T21 made the switch bar transparent ("no background"), which left the sticky Grid/Full-size labels over scrolling photos. T18 made the grid full-bleed, so the title and bar were the only elements still spanning the full viewport.
- Options weighed: (a) re-paint the whole sticky bar solid - rejected, Pedro asked for the bar itself to stay background-less; (b) solid background on the option buttons only, matching the page's background color - chosen; (c) translucent chip plate (the workflow strip's --cs-chip-plate trick) - rejected, Pedro said "match the background color", i.e. solid, not a whisper.
- Decision: `.photoview-btn { background-color: $vb-dark }` (#18181b, the same value as the page's base background, so the pills read as cut out of the page and block photos when stuck). `.photoview-title` and `.photoview-switch` get `max-width: 900px; margin: 0 auto` - the galleries' content width - so title and controls sit on the same line as other pages' content; the grid stays full-bleed. Ticket 24.
- Rationale: at rest the pills blend with the dark ground (same color); when the bar sticks over photos, each option remains a solid dark pill - readable, no photo bleed. The 900px alignment keeps the page's header row consistent with the other gallery pages without re-capping the grid.
- Consequences: if the photography page background ever changes from #18181b, the button background must change with it (same token, $vb-dark - one place). Below 900px viewport the title/bar simply span full width.
