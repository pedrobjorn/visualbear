# DR-0016 — `::: callout` joins the case-study container set (callout tile with stretched pill link)

- Date: 2026-11-20
- Status: accepted (shipped in the teachr-case-study polish pass, specs/teachr-case-study/DR-0004 ticket 18)
- Context: case studies had no way to put a prominent outbound link (e.g. to a live mock app) inside a section — the hero `related` meta item is the only quiet link slot and it is single-use. The teachr page needed a callout tile linking `/teachr-app/`.
- Decision: new container `::: callout`. First line `[callout: Title | href | Link text]`, remaining lines are the body (normal flow). Renders:

  ```html
  <div class="cs-callout">
    <div class="cs-callout-text">
      <h3>Title</h3>
      …body…
    </div>
    <a class="cs-callout-link" href="…">Link text <i class="ph ph-arrow-right"></i></a>
  </div>
  ```

  Styles: plate background (`--cs-chip-plate`), 4px `var(--cs-accent)` left edge, radius 16, flex row (text left, pill right) at ≥768px, column below. The pill uses the new `--cs-accent-deep` theme token (white-text-safe: teal #0e7d6f 5.02:1, pink #d50e95 4.85:1, black #111, default #d0181e 5.5:1), uppercase label, and a stretched `::after` (inset 0 on the positioned tile) so the whole tile is one click target while the link stays keyboard-focusable with `:focus-visible` + `:focus-within` rings. The pill pins its own hover/focus/active states (DR-0017) so theme link rules never recolor it.

- Wiring: registered in `renderContainer` (`markdown-render.js`), documented in AUTHORING.md (doc-sync gate `tools/doc-sync.sh` covers it), emitted by a new `Callout:` label rule in `specs/text-to-md/tools/draft-to-md.js` (label + following plain lines until blank/heading/label/bold = the block). In drafts: `Callout: Title | href | Link text` + body lines.
- Consequences: any case-study page can use `::: callout`. Optional follow-up (not built): a callout specimen in the /styleguide/ casesystem block.
