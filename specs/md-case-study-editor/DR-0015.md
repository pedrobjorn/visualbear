# DR-0015 — /styleguide/ stays public and becomes a second host of the visuAI / Design system tab system; the design-system guide copy is list-ified, de-dashed, and AI-tagged

- Date: 2026-11-14
- Status: accepted (Pedro's eval pass 2026-11-14). Supersedes the "retire /styleguide/" gate in visualbear-system Ticket 4 / open question 1: the design system page stays public AND carries the tabs.
- Context: /workflow/ already hosts the two-tab system (strip + visuai/designsystem panels, body class pair). /styleguide/ rendered the same styleguide blocks without a strip. The guide copy had ~15 em dashes in rendered text, running paragraphs, and untagged AI-drafted prose.
- Options weighed: (a) retire /styleguide/ and redirect to /workflow/ (the old pending Ticket 4) - rejected by Pedro's instruction; (b) add the full strip + both panels to /styleguide/, defaulting to Design system - chosen; (c) make the tabs plain links between the two URLs - rejected, the tab pattern is in-page switching with ground swap, and the user asked for the tabs themselves.
- Decision: (b). /styleguide/ renders the visuAI panel (workflow article) + Design system panel (the five blocks), strip active = designsystem, body class `vb-system-light` initially; tabs.js now initializes from the strip spec's `active` (falls back to DEFAULT_TAB, so /workflow/ is unchanged). Copy pass (ticket 63): em dashes removed from rendered text, guide prose converted to short lists, copy trimmed, and every agent-drafted section tagged `<div class="ai-mark">✦ AI-drafted</div>` (dev-only chip; production strips and warns until Pedro rewrites - the DR-0008 contract).
- Rationale: one tab system, two public entry points; the guide's demo specimens stay untouched so the page cannot drift from the code, while the prose around them gets shorter and honestly attributed.
- Consequences: /styleguide/ and /workflow/ share the panel content - a copy edit in the styleguide blocks shows in both (intended). tabs.js's initial-state change is covered by the core-only test contract (DEFAULT_TAB behavior preserved when no spec). The production build will warn about the new ai-mark blocks until Pedro rewrites them - expected, not a regression.
