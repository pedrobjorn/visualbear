# DR-0014 — One hero component: one spacing set, three variants

- Date: 2026-10-31
- Status: ACCEPTED (Pedro, 2026-10-31: "case study heroes should be a
  shared component and consistently spaced")
- Context: measured hero matrix, 2026-10-31 — FOUR different spacing
  sets across the hero instances: covers 64/64, meta 32/32, the coupon
  `::: hero` 128/32, workflow 88/40 — held together by cascade
  accidents, not rules.

## Findings (measured)

1. The covers' 64/64 is an override accident: the base rule says
   64/32, a `padding-top: 128px` rule (≥1279, "let the hero breathe")
   is overridden for every real cover by the variant rule — it only
   ever hit the coupon hero (128/32) and would hit any future bare
   hero. A ≤767 `padding-top: 32` rule is likewise dead for covers.
2. The workflow (visuAI) hero: 88/40 padding (the dark theme's
   "breathing room"), and it MISSES the cover type roles entirely —
   they are scoped inside the colored-cover selector — so its summary
   renders at body size (18.432 vs the cover's 22.464) and its
   details at body size (vs label 15.36), with gaps 16/0 vs 24/24.
3. The coupon hero's subtitle/byline sit flush (mt 0) where the cover
   puts 24.
4. The meta block is consistent (32/32; 24 top below 1280; kids mt 32)
   — unchanged.
5. Sections: 64 everywhere; workflow runs 88.

## Decision

**One hero spacing/type set, three variants:**

1. **All heroes** (`.case-study .cs-hero`): `padding: 64px 0`; title
   margin 0; summary (`.cs-cover-summary`) 22.464 light, mt 24;
   details/byline 15.36, mt 24. Colors inherit — the variant scopes
   set the ink.
2. **Covers** (`cs-hero--pink/red/black/teal`): keep the full-bleed
   box: `padding: 64px 48px` (48 = the viewport-safe inset), white ink.
   The dead 128 rule and the dead ≤767 pt-32 rule are DELETED.
3. **Meta** (`cs-hero--meta`): `padding: 32px 0` (24 top below 1280);
   kids mt 32 — unchanged.
4. **Workflow joins the shared set**: the 88/40 hero override and the
   88px section padding are deleted; its hero inherits the type roles
   (summary 22.464, details 15.36, gaps 24) on the dark ground.
5. The mid-page `::: hero` gets 64/64 (the divider above carries the
   section break) and its subtitle/byline take the 24 gaps.

## Consequences

- Future heroes get the correct spacing and type roles by default —
  a bare `cs-hero` is enough; variant classes only choose ground/ink.
- The workflow page loses its extra "breathing room" — deliberate
  supersession per this record; if the dark page needs air again, it
  is a token change, not per-rule overrides.
- The rhythm scale (ticket 21) now governs the hero completely:
  16 label pair, 24 content gaps, 32 meta, 64 section/hero padding.
