# DR-0002: Optional frontmatter is added for hero/meta overrides

- Date: 2026-10-29
- Status: accepted
- Context: Hero title/summary/details are derived by position convention; SEO title and hero images cannot be expressed in md. Pedro answered the plan's open question: yes to frontmatter.
- Decision: Support a minimal `---` delimited frontmatter block at the top of md files, parsed before marked in `renderMarkdown`. Keys are used only for shell/meta injection and never rendered as body content. Convention-driven derivation (DR-0001) remains the default when no frontmatter is present.
- Consequences: `mdPage`/`mdResume` must split frontmatter from body and expose it (e.g. as a property the nunjucks shell reads). Every md file without frontmatter renders exactly as before. The authoring guide (Ticket 1) documents the supported keys.
