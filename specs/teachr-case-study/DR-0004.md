# DR-0004: Teachr polish pass — hero logo/arrows, KPI row, shots alignment, app callout

- Date: 2026-11-20
- Status: accepted
- Context: after the 2026-11-18 fold landed, a visual pass over `/selected-works/teachr/` at 1440/390 (Playwright measurements, see Evidence) found six issues: the 19px brand logo under the hero cover, arrow icons in the KPI labels, the 4 KPIs wrapping 3+1 instead of one row, desktop+mobile shots rows whose image heights drift apart at ~1280-1366px, the avatar pop-out shot much wider than the phone shot next to it, and no way to reach the `teachr-app` mock from the case study.
- Decisions:
  1. **Logo removed at the source**: delete the `Logo:` head line from `src/_data/drafts/teachr.txt`. The renderer (`heroMetaItemHtml`) only renders meta keys present, so no renderer change is needed; the 19px `<img>` disappears from `.cs-hero--meta`.
  2. **KPI arrows removed everywhere**: strip `↓`/`↑` from the 4 hero `Metrics:` labels AND from the conclusion `::: metrics` values (`↓80%` -> `80%`). `iconify()` in `markdown-render.js` then has nothing to iconify; values count up plain. The footnote markers `*`/`**` stay attached to the labels.
  3. **KPI row**: at `>= $break-medium` (768px) `.cs-metric` becomes `flex: 1 1 0; min-width: 0; margin: 16px 8px; padding: 24px 12px`, so all 4 cards share one row at the 916px meta measure (measured before: 3x273px + 1x884px = 3+1). Below 768px the existing wrap (basis 200px, 2x2 then 1-per-line) is unchanged.
  4. **Shots equal height**: the `min-width: 240px` clamp on `.cs-shot` breaks the renderer's aspect-ratio-proportional `flex-grow` whenever a phone shot's proportional width < 240px (measured at 1440: avatar-menu settings clamped to 240 -> 506px tall vs pop-out 416px; at 1280: completion mobile 506 vs desktop 438). Fix: `min-width: 0` on `.cs-shot` at `>= $break-medium`, so width_i stays proportional to ratio_i and every image height = container/Σratio comes out equal. Below 768px the 240px floor stays, so phones still stack.
  5. **Avatar-menu pair**: scoped to `#avatar-menu`, both shots get `flex: 0 1 240px` (beating the inline aspect-ratio grow via author `!important`) + `justify-content: center` + `align-items: flex-start` — the pop-out renders at the same 240px width as the phone detail next to it, tops aligned, the pair centered. Other shots rows are untouched.
  6. **New `::: callout` container** (registered in `renderContainer`, documented in AUTHORING.md, emitted by a new `Callout:` label rule in `draft-to-md.js`): renders `.cs-callout` tile = plate background, accent left border, h3 title, body, and a pill link `.cs-callout-link` (stretched over the tile, arrow icon, theme `--cs-accent-deep` background). Used once: new `## Try the mock app | Live demo | try-app` section after `ai-workflow`, linking `../teachr-app/` (resolves to `/selected-works/teachr-app/`, 200 in the mirror; teachr-app stays air-locked). New copy carries `[ai]` per DR-0008.
- Alternatives rejected: (a) fixing KPI wrap by widening the meta container — would break the shared text measure (DR-0013); (b) equalizing shot heights with `object-fit: cover` — crops content; (c) making the whole callout a hand-written HTML block in the draft — bypasses the converter, lost on re-conversion (DR-0003); (d) linking the app from the hero `related` meta — the related slot is already used for the teachr-agent pair, and the request is a section after the setup.
- Consequences: `::: callout` is now part of the authoring contract (doc-sync gate covers it); any page may use it. The KPI/arrow removal applies to the teachr page only (copy change); the CSS rules are shared but behavior-preserving elsewhere (other pages' metrics rows also become 4-across at >=768, which is the intended reading of the component).
- Evidence: Playwright measurements at 1440 before the change — KPI cards 3x(273px @y796)+1x(884px @y978) in a 916px container; hero logo img 19x19 present; 4 `.ph-arrow-*` icons in hero meta; avatar-menu figs 824x535 vs 240x535 (img 416 vs 506); library figs 800x588 vs 264x588. After: captures in `evidence/teachr-{1440,390}-polish-*.png`.
