# DR-0003: New `::: wide` container replaces full-bleed images in the Teachr case study (75/85/90% width)

- Date: 2026-11-18
- Status: accepted
- Context: after DR-0002, the Teachr page still had full-bleed (100vw) imagery — both the `::: shots` bands and the wide showcase tier (`.cs-showcase--wide`). The request was to pull all "full bleed" images in this page in to a narrower, centered container.
- Decision: introduce a new container `::: wide` ("Wide images") rendered as `.cs-wide-img`, sized:
  - desktop (>767px): 75vw, centered (`left:50%; margin-left:-37.5vw`)
  - tablet (<=767px, `$break-medium`): 85vw
  - mobile (<=480px, `$break-small`): 90vw
  - vertical margins 40px / 56px (mobile/desktop) as before
  - all-image line runs inside `::: wide` render as a shots row (reusing `renderShots`, so equal-height figures from DR-0002 apply); non-image lines render as normal flow content.
- Scope: `::: wide` is applied to every previously full-bleed image in the Teachr page — the 4 image runs in `src/_data/drafts/teachr.txt` now emit `::: wide` (converter rule 6b in `specs/text-to-md/tools/draft-to-md.js` changed from `::: shots` to `::: wide`; `specs/text-to-md/DR-0004.md` amended to match), and the wide showcase tier `.cs-showcase--wide` (used only by the Teachr page) is re-skinned from 100vw to the same 75/85/90vw widths. `::: shots` itself stays full-bleed for any other use. No other page uses `::: wide` yet; the container is registered in `renderContainer` (`markdown-render.js`) and documented in AUTHORING.md + the styleguide casesystem block.
- Consequences: captions on wide runs live in the alt text as before; deleting a shot = deleting its line. Zero `cs-wide--full` elements remain on the Teachr page.
- Evidence: measured at viewports 1440/700/390 — every `.cs-wide-img` band and `.cs-showcase--wide` measures 1080/595/351 px = exactly 75%/85%/90% of the viewport. Captures: `specs/teachr-case-study/evidence/teachr-{1440,700,390}-wide-*.png`, `teachr-390-wide-showcase-0.png`.
