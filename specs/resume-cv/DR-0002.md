# DR-0002: edits go to resume.md + the title block only; the other \_resume_blocks macros are dead code and stay untouched

- Date: 2026-11-15
- Status: accepted
- Context: `src/resume/index.nunjucks` imports only `resume.title.nunjucks` and
  `resume.end.nunjucks`. The macros `resume.intro/skills/experience/education/
languages/interests.nunjucks` still exist in `src/resume/_resume_blocks/`
  and contain a stale copy of the CV (10+ years, old skills order), but nothing
  renders them - the body comes from `src/_data/pages/resume.md` through the
  `mdresume` filter.
- Decision: the CV refresh edits exactly two files: `src/resume/_resume_blocks/
resume.title.nunjucks` (header) and `src/_data/pages/resume.md` (body). The
  dead macros are left byte-identical.
- Rationale: AUTHORING.md keeps the bespoke hero in the page shell and the
  content in the md; the shell/md split is the live architecture. Deleting or
  updating the dead macros would either be a destructive cleanup this spec
  was not asked for, or busywork on unrendered code - and a stale duplicate is
  safer left alone than half-synced.
- Consequences: anyone grepping the repo for "10+ years" will still find it in
  the dead macros; that is expected. A future cleanup ticket may remove them,
  recorded here so nobody "fixes" the wrong copy during this change.
