- Date: 2026-11-15
- Status: accepted (assumption recorded, open question for Pedro, non-blocking)
- Context: the 2026-11-15 CV was pasted verbatim by Pedro as the copy source.
  Two things needed a decision: (a) whether any of it carries the `[ai]`
  AI-drafted marker, (b) the block headed "Key Achievements" that contains the
  four degrees (2011 Future Games ... 2002 St. Julian's) - clearly a
  copy-paste slip for "Education", since every role already has its own Key
  Achievements list.
- Decision: (a) no `[ai]` markers anywhere in this change - the DR-0008
  contract marks agent-drafted copy only; this copy is Pedro's own, verbatim.
  (b) The degrees map to the existing `## Education |` quiet section of
  `src/_data/pages/resume.md`; the stray "Key Achievements" heading is dropped,
  not rendered as a section.
- Rationale: marking the owner's own pasted words as AI-drafted would be a
  false attribution and would make the production build warn. The education
  entries already exist in that section with identical wording, links, and
  country notes, so the mapping is a verify-only ticket, not new copy.
- Consequences: the build stays free of new AI-attribution warnings; if Pedro
  actually meant a separate achievements section, that is a new spec, not a
  fix to this one.
