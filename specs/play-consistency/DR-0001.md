# DR-0001: The home Play tile is removed completely, including the mirror strip that targeted it

- Date: 2026-11-17
- Status: accepted (pending build)
- Context: the Play teaser card (`id="play-teaser"`, `card--thin`) renders as the last card of the home work gallery (play-subpages T2/DR-0003) and is stripped from release-mirror output by `stripPlayTeaser` (scripts/mirror-link.js) because `/play/` is not mirrored and its `../play` href would escape the mirror air-lock (guard 8). Pedro wants the tile gone. With the tile gone, `stripPlayTeaser` matches nothing and is dead code.
- Options weighed: (a) keep `stripPlayTeaser` as a defensive no-op - rejected, it targets an element that can no longer exist, and its tests would keep asserting behavior for markup nothing produces; (b) remove the tile render, the `showPlay` param, `card--thin`, `stripPlayTeaser`, and the related test assertions - chosen; (c) also remove the never-rendered `_blogCard`/`showBlog` machinery - rejected for now, out of scope; the only work-branch caller already passes `showBlog: false` and Pedro did not ask about a Blog tile.
- Decision: remove the Play card block, `_playCard`, and `_showPlay` from `src/_modules/organisms/gallery/gallery.nunjucks`; drop `showPlay:true` from `src/index.nunjucks`; remove `.card--thin` from `card.scss`; remove `stripPlayTeaser` from `scripts/mirror-link.js` and its call + comment from `scripts/release-mirror.js`; update `scripts/test/mirror-link.test.js` and `scripts/test/gallery-order.test.js`.
- Rationale: dead code that references a removed element is worse than no code; the mirror guard exists to strip public-only cards, and with no card there is nothing to strip. Full removal keeps `grep play-teaser` empty, which is itself a regression check.
- Consequences: `/play/` becomes unlinked from the home page (it already has no nav link). If Pedro wants `/play/` reachable, that is a separate nav decision (plan Open questions). The release mirror no longer needs the play-teaser strip; guard 8's comment is removed with the call.
