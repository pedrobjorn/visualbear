# DR-0008: The public home's pill links to the public work section - the air-lock keeps its path

- Date: 2026-11-12
- Status: accepted (Pedro, 2026-11-12e: pill on the main page links to the public work section)
- Context: Pedro asked for the robot pill on the main page "as well, not
  just selected works". The blocker (DR-0004) was that any href from the
  public home either 404'd or disclosed the air-locked mirror path -
  release-4.0's sneak-property is that the path is referenced NOWHERE on
  the public side ("information is the password", DR-R4-0003; guard
  check 3 greps for it).
- Options weighed: (a) link into the mirror - discloses the path on the
  most-discovered page of the site, breaks the password model and guard
  check 3; (b) decorative-but-expanding, no href - a hover label with no
  follow-through; (c) link to the public work gallery.
- Decision: (c). The public home's `.floating-robot` span becomes
  `<a class="robot" href="#work">` with pill label "selected works"
  (aria-label + title), same 44x44 geometry and 20px glyph as the
  mirror pill (tickets 18/19 state). The mirror injector strips the
  public pill from mirror copies, so the mirror home still renders
  exactly one robot - its own, linking to the in-mirror workflow pages.
  Guard check 6's public-home exclusion keeps holding: the public pill
  carries no mirror-visuai mark and no mirror path.
- Rationale: Pedro chose the public work section explicitly. The pill
  gets full parity (link states, expansion, a11y name) with a target
  that resolves for every visitor; the air-lock's secrecy guarantee
  ("no link on the public side" - release-4.0 plan) is scoped down
  knowingly only so far as it never names the mirror or the moved
  pages, which it still does not.
- Consequences: Supersedes DR-0004's unlinked-half for the public index
  (the decorative span's geometry/layers carry over into the link).
  DR-0004's sentence "if the visualbear system merge later gives the
  public a legitimate destination, the span can gain an href in one
  line" is this record's executing precedent. The guard needs no
  change. The strip in release-mirror.js must stay targeted (the
  public pill's distinctive href="#work") so it can never eat the
  mirror's own injected link on a re-run.
