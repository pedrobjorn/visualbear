# DR-0010: The visualbear-system page is public at the root (duplicated, not rewritten)

- Date: 2026-11-13
- Status: accepted - supersedes DR-R4-0002 for the `workflow` route ONLY
- Context: Pedro (2026-11-13): "index is always public home otherwise it's
  mirror or selected works. Make the robot link to the visuAI / design
  system page on the index... just duplicate the pages and add them to
  root, simple - don't rewrite the whole thing." The merged system page
  (`/workflow/`, visuAI + Design system tabs) was pruned from the public
  root by the air-lock (DR-R4-0002), so the public home's robot pill
  pointed at `#work` (T20) to avoid disclosing the mirror path.
- Decision: ship the fresh gulp build's `build/workflow/` at the public
  root as-is - a plain duplicate, no rewrite - and remove `workflow` from
  the prune list (`SECRET_DIRS` in scripts/release-mirror.js). The mirror
  keeps its own rewritten copy under `build/<mirrorPath>/workflow/`
  (noindex + depth-relative nav + its own robot) exactly as before.
  The public home's robot pill now links `workflow/` (depth 0) with the
  truthful accessible name "The visualbear system" (T30). teachr and
  teachr-agent stay air-locked. Guard amended: check 2 prunes/asserts only
  teachr*, plus a new positive assertion that public build/workflow/
  exists; the mirror-path leak checks are unchanged and still cover
  everything.
- Rationale: Pedro explicitly reversed the air-lock for this one route.
  Duplication (not rewriting) keeps the mirror pipeline untouched and the
  public page byte-equal to the dev build - the smallest honest change.
  The remaining air-lock (teachr*) and the "information is the password"
  posture (DR-R4-0003) for the mirror PATH itself are unaffected: the
  mirror path still appears nowhere public.
- Consequences: the public pill's href now equals the mirror root robot's
  href string ("workflow/"), so the mirror strip pass targets the public
  pill via a new `data-vb-public-pill` marker instead of the href
  (mirror-link.js + tests updated, idempotency preserved). /workflow/ is
  added to src/sitemap.xml. Any future "secret" status for workflow needs a
  superseding DR.
