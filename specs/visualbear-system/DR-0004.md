# DR-0004: The robot mark also appears on the public index - decorative, unlinked

- Date: 2026-11-12
- Status: accepted (Pedro, 2026-11-12: "we can keep the robot icon in the index also")
- Context: release-4.0 R4-9b gave the floating link to every MIRRORED page and explicitly none to the public root, because the link's destination (/workflow/) is air-locked. Pedro now wants the robot visible on the public home too.
- Decision: The public index (and only the public index) carries the robot as a decorative, ARIA-hidden span (`.floating-robot`, src/index.nunjucks) - same spot (fixed bottom-left), same layer (z-index: 3), but no href. The mirror injector strips that span from every mirror copy and injects its own linked robot instead, so no page ever renders two robots stacked.
- Rationale: A public link into /workflow/ would either 404 (the release prunes the public page, DR-R4-0004 hygiene) or leak the air-locked destination; an unlinked mark carries the brand flourish with zero routing surface. Stripping instead of hiding keeps the mirror copies byte-honest - nothing public-only ships in them.
- Consequences: R4-9b's "public root gets none" is superseded for the index only; the release-guard's leak grep stays untouched (no secret path in the public markup). If the visualbear system merge (DR-0002/DR-0003) later gives the public a legitimate destination, the span can gain an href in one line. Marked aria-hidden: it is decoration, not a link, and must not enter the accessibility tree or tab order.
